# Network Security Auditor Project

### Reflection

**What was the hardest part?**

The hardest part of this task was setting up the environment and working with tools I was not familiar with. This was my first time using Python in a practical project, so installing packages like `boto3` and getting everything to work properly was a bit confusing at first. I also struggled with AWS configurations like choosing the right region, creating roles, and setting up MFA since I didn’t fully understand how permissions and authentication worked. Fixing credential errors and getting the script to run successfully took some trial and error. Understanding security group rules and why some of them are considered risky was also something I had to learn along the way.

**What would you add next?**

If I continue working on this, I would try to improve my understanding of how the script works and maybe make small improvements like checking more ports or making the output clearer. I would also like to get more comfortable with AWS and Python so I can build something more complete over time.
